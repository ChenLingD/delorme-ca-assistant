# 关键决策与假设

## 品牌
- 虚构品牌：**Maison Delorme 德洛姆**，1887 年创立于巴黎旺多姆广场的高级珠宝世家；1920 年代从上海采购南洋珍珠，形成“沧海”珍珠系列（东方元素的由来）。
- 查重：未发现同名珠宝世家；存在法国家纺品牌 Yves Delorme 与零星小型珠宝店，品类不同，判断可接受（如需可改名，品牌名集中在 `brand/` 中）。
- 定位与客群参照顶级奢侈品牌：**不打折**；明星款实行**配额文化**——价格不是门槛，关系才是；但 CA **绝不明说**任何消费门槛（“配货”）。

## 输出
- 每次输出 3 条中文微信候选消息；3 条在“策略角度 × 篇幅/正式度”两个维度上拉开差异。
- 消息要像真人说话：短为常态，不写长段落。
- 每条附“给 CA 的备注”（策略与适用情况），**只给 CA 看**，不发送给客户。
- 生成前先做**时机与风险判断**（如未解决投诉、客户明确拒绝推销、家庭变故、礼赠关系需保密），必要时提醒 CA 并给出更克制的版本。

## 输入
- 客户画像使用中性、可观察字段；系统内不出现贬义标签。7 类客群只作为测试集的覆盖维度。
- CA 身份作为输入（姓名、从业年限、与客户认识多久、说话风格、门店）。
- 只做简体中文；繁体/粤语列入下一步。

## 技术与评估
- 生成模型：在约 10 个用例上做多模型 bake-off，按数据选出主模型。参赛模型（兼顾前沿能力与性价比）：
  OpenAI `gpt-6.1-terra`、Anthropic `claude-sonnet-5-5`、Google `gemini-3.8-flash`、DeepSeek `deepseek-flash`（V4.1 Flash 的稳定 API 名，账户仅开放 `deepseek-flash` / `deepseek-v4-pro`，旧名 `deepseek-v4-flash`、`deepseek-chat` 均路由到它）、Kimi `kimi-k3.1-pro`。
- Judge 使用与主生成模型不同家族的模型；用人工标注子集校准 judge 并报告一致率。
- v0 = 单 prompt 基线（对照组）；v1 = 流水线；测试后迭代 v2。每条结果标注版本。
- 不使用完整话术 few-shot（防止重复）；改用风格原则 + 短语级 do/don't + 陈词黑名单，并把跨用例重复度作为量化指标。
- 产出：说明文档 + 50 用例 Excel（用例表 + 附加 sheet 放版本/评分）+ 代码仓库 + 轻量 Streamlit demo。
